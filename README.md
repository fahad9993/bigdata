## Dataset

**Download:** [ASHRAE — Great Energy Predictor III (Kaggle)](https://www.kaggle.com/competitions/ashrae-energy-prediction/data)

The downloaded dataset is approximately **2.43 GB**, so **raw data files will not be uploaded to this GitHub repository**. Each member could download the data separately. A Kaggle account and acceptance of the competition rules may be required.

After downloading, extract the files into the following folder:

```text
data/
└── raw/
    ├── building_metadata.csv
    ├── train.csv
    ├── test.csv
    ├── weather_train.csv
    ├── weather_test.csv
    └── sample_submission.csv
```
